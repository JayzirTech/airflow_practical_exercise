Configuración de Amazon RDS (PostgreSQL) Guía Técnica

Paso a paso detallado para aprovisionar y asegurar una base de datos PostgreSQL en Amazon RDS bajo buenas prácticas de infraestructura.

1. Método de Creación y Motor

  • Método: Seleccionar Full configuration (Configuración completa) para tener control total de los parámetros de red, seguridad y almacenamiento en lugar de usar opciones predefinidas.
  • Motor de Base de Datos: Elegir PostgreSQL con una versión estable y compatible para producción.

2. Gestión de Credenciales

  • Opción de Credenciales: Elegir Self managed (Autogestionada) para introducir manualmente la contraseña maestra que previamente resguardamos en AWS Secrets Manager.
  • Usuario Maestro: Definir un nombre claro (ej. airflow) alineado con los parámetros de la arquitectura.

3. Conectividad y Red (Seguridad Crítica)

  • VPC: Asignar la misma Red Privada Virtual (VPC) donde residirán los componentes de cómputo (EC2 y ECS).
  • Acceso Público (Publicly accessible): Marcar obligatoriamente en No para impedir que la base de datos quede expuesta a Internet; solo la red interna de AWS podrá comunicarse con ella.
  • Grupo de Seguridad (VPC security group): Crear un grupo de seguridad dedicado (ej. airflow-rds-sg) configurado para permitir tráfico entrante exclusivamente en el puerto 5432.

4. Configuración Adicional

  • Nombre inicial de la base de datos (Initial database name): Indicar explícitamente un nombre (ej. airflow_db). Si se omite, los servicios de Airflow fallarán al intentar buscar una base predeterminada en el primer arranque.
